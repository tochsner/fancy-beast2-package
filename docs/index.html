BEAST 3 package

FancyModel

A nucleotide substitution model where every substitution secretly detours through a hidden fifth state.

What it is

FancyModel is a nucleotide substitution model for BEAST phylogenetics. It assumes a fifth, hidden nucleotide X that is never sampled or observed. Direct substitutions between the four conventional nucleotides (A, C, G, T) are impossible — every substitution must pass through X first.

The rate between a nucleotide and X is proportional to how far apart the two letters sit in the English alphabet (A…Z). Concretely, the rate equals baseRate times the number of letters strictly between them:

rate(N ↔ X) = baseRate × |letters between N and X in A..Z|

For example, T↔X has rate baseRate × 3, since U, V and W lie between T and X in the alphabet.

NucleotideAlphabet positionLetters to X (position 24)Rate to X
A122 (B…W)22 × baseRate
C320 (D…W)20 × baseRate
G716 (H…W)16 × baseRate
T203 (U, V, W)3 × baseRate

Because every nucleotide reaches X by the same symmetric mechanism, the rate matrix is time-reversible with a uniform stationary distribution: each of the five states (A, C, G, T, X) has equal 1/5 probability at equilibrium, so among the four observable nucleotides, base frequencies are fixed at a uniform 0.25 each rather than being user-specifiable.

Internally, FancyModel builds and eigendecomposes the full 5×5 rate matrix over (A, C, G, T, X), then returns the 4×4 block restricted to the observable nucleotides for transition probabilities and the rate matrix — the detour through X is fully accounted for within a single branch's transition probability.

Parameters

InputTypeRequiredDescription
baseRate RealScalar<PositiveReal> yes Rate multiplier applied to the alphabet distance between a nucleotide and the hidden state X.

frequencies is not accepted — supplying it raises an error, since the rate symmetry forces a uniform equilibrium distribution.

Using it in a BEAST XML analysis

Wire FancyModel into a site model exactly as you would any other nucleotide substitution model (e.g. in place of HKY or GTR): 

<input spec="my.beast.example.FancyModel" id="fancyModel">
    <baseRate idref="fancyModel.baseRate"/>
</input>

<input spec="beast.base.spec.evolution.sitemodel.SiteModel" id="siteModel" gammaCategoryCount="1">
    <substModel idref="fancyModel"/>
</input>

<parameter id="fancyModel.baseRate" value="1.0"
           spec="beast.base.spec.inference.parameter.RealScalarParam"
           domain="PositiveReal"/>

A complete runnable example — a 6-taxon primate alignment analyzed with FancyModel under MCMC — ships with the package at src/test/resources/my.beast.example/examples/testFancyModel.xml.

Installing the package

  1. Build the package archive with ./release.sh (or your usual Maven build).
  2. Install it into your BEAST packages directory, or install via the BEAST Package Manager once published.
  3. Reference my.beast.example.FancyModel as the substModel in your BEAST XML, as shown above.
